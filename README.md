# Ohm Lab — індивідуальний DevOps-проєкт

Довжук Тимофій Андрійович · КН-41

Вебкалькулятор сили струму й потужності з Node.js API, PostgreSQL, Docker,
GitHub Actions та інфраструктурою AWS EC2 у Terraform.

**[Код, локальний запуск, налаштування AWS та інструкція здачі](students/dovzhuk-timofii/README.md)**

Структуру адаптовано за [завданням Max-K44/devops-template](https://github.com/Max-K44/devops-template).
Репозиторій продовжує історію попередніх практичних робіт; це не новий репозиторій,
створений кнопкою Use this template. Якщо викладач вимагає саме цю процедуру,
потрібно створити новий репозиторій із шаблону й перенести туди папку students та кореневу .github.

Робочий workflow розміщено в кореневій `.github/workflows/ci.yml`, де GitHub Actions його знаходить.

Наявність конфігурації не підтверджує деплой: для здачі потрібен успішний запуск
Actions із виконаним job `deploy` та доступний застосунок на EC2.
